# Changelog

## 0.1.0

- Rule engine for Indian offer-scam patterns: fees, deposits, UPI requests, Telegram-only HR,
  free-mail recruiters, lookalike brand domains and pressure tactics.
- Calibrated ML model trained on EMSCAD, with an evaluation and error-analysis report.
- FastAPI service with `/check` and `/health`, and anonymous daily usage counts.
- Next.js web app with highlighted reasons and a verification checklist.
- Chrome extension that checks selected text or the current page.
- Static demo on GitHub Pages and a CI pipeline with lint, tests and a Docker smoke test.
- Optional Gemini explanations in other languages, with a rule-based fallback.
