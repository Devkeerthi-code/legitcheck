# LegitCheck Chrome extension

Select an internship or job offer on any page, right-click, choose **Check with LegitCheck**,
and the popup shows the verdict, the score, the top 3 warning signs with their exact words,
and the verification checklist. Clicking the toolbar icon with nothing selected checks the
main text of the page you're on.

Manifest V3, plain JavaScript modules, no build step.

## Load it

1. Start the API (see the root README). By default the extension talks to `http://127.0.0.1:8000`.
2. Open `chrome://extensions`, turn on **Developer mode**, click **Load unpacked** and pick this `extension/` folder.
3. Optional: copy the extension ID into the API's `EXTENSION_ID` env var to lock CORS to it.

## Point it at a deployed API

Edit `config.js` (the only file you need to change):

- `API_URL`: your API, e.g. `https://legitcheck-api.onrender.com`
- `WEB_APP_URL`: your web app, used by "Open full report"

Then replace `host_permissions` in `manifest.json` with the same API origin
(e.g. `["https://legitcheck-api.onrender.com/*"]`) and click reload in `chrome://extensions`.

## Permissions, and why

| Permission | Why |
| --- | --- |
| `contextMenus` | The "Check with LegitCheck" item on selected text. |
| `activeTab` | Read the current page only after you click the icon or the menu item. |
| `scripting` | Run the one small function that extracts the page's main text (`extract.js`). |
| host: API origin only | Send the text to the LegitCheck API. |

No `storage`, no `tabs`, no `<all_urls>`. The selected text is kept in the service worker's
memory until the popup takes it, then cleared. Nothing is saved anywhere.

## Files

- `manifest.json`, `config.js`: setup
- `service-worker.js`: context menu, holds the pending selection in memory, opens the popup
- `popup.html`, `popup.css`, `popup.js`, `render.js`: the popup UI and its states
- `extract.js`: the page-text extractor injected on toolbar click
- `icons/`: generated by `scripts/make_icons.py` (standard library only)
- `fonts/`: Geist and Geist Mono (SIL Open Font License, see `fonts/OFL.txt`)
